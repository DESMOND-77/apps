## Présentation du projet

Ce dépôt regroupe plusieurs applications et scripts Python organisés en différents dossiers. Voici la structure et le contenu principal :

### Structure du projet

- `python/`
	- `CESAR code/`
		- `decoder` : Script ou module pour le décodage du code César.
	- `file manager/`
		- `main.py` : Point d'entrée du gestionnaire de fichiers.
		- `file_class_window.py` : Fenêtre de classification de fichiers.
		- `del_b_ext_window.py` : Suppression de fichiers par extension.
		- `dup_rem_window.py` : Suppression de doublons.
		- `assets/` : Ressources graphiques (icônes, images, feuille de style CSS).
	- `youtube_downloader/`
		- `Youtube Downloader Premium.py` : Script pour télécharger des vidéos YouTube.
	- `tests.py` : Fichier de tests pour les différents modules.

### Utilisation

Chaque dossier contient des scripts indépendants. Pour exécuter un script, placez-vous dans le dossier correspondant et lancez le fichier Python souhaité. Par exemple :

```bash
cd python/file\ manager
python3 main.py
```
